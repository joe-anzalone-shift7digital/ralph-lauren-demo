# RL Data Wedge — Lightning Web Component

Tabular planned assortment workspace for the Ralph Lauren B2B demo.
Sibling component to `rlPictureWedge` — shares the same Apex controller
and data model. Deploy this package AFTER the data model and picture wedge packages.

## What's in this package

| File | Purpose |
|------|---------|
| `rlDataWedge.js` | Controller — data pipeline, sort/filter/group, CSV export |
| `rlDataWedge.html` | Template — table, group headers, size rows, modals |
| `rlDataWedge.css` | Styles — table, tier pills, variance chips, door bars |
| `rlDataWedge.js-meta.xml` | Metadata — targets, buyerMode, maxDoors properties |
| `RLAssortmentController.cls` | **Updated** Apex controller — adds `getSizeRunsForPlan` |
| `RLAssortmentControllerTest.cls` | **Updated** test class — adds size run test coverage |

> ⚠️ This package includes an **updated version** of `RLAssortmentController.cls`.
> It is backwards-compatible — only adds the new `getSizeRunsForPlan` method.
> Deploying this package will replace the controller from the Picture Wedge package.
> Both LWCs will continue to work correctly.

## Features

**Sortable columns** — click any column header to sort ascending/descending:
- Sequence (default), Planned Units, Variance %, Extended Cost, Doors

**Group by** — reorganises rows into labelled sections with group subtotals:
- FOB (Family of Business) — default
- Tier (A / B / C)
- Delivery window
- None (flat list)

**Filters** — filter the displayed rows instantly:
- All, Hero styles, Below target >5%, Tier A, Tier B, Tier C

**Search** — live search across style number, product name, and colorway

**Size run drill-down** — click the expand icon on any row to reveal the
full size break (from `RL_Size_Run__c`) in a sub-row beneath

**Row selection** — checkbox multi-select with a bulk action bar

**Buyer mode** — read-only view for Experience Cloud:
- Buyer Status combobox per row (Approved / Flagged for Discussion / Dropped)
- Buyer note annotation per row
- No hero toggle, no drag, no lock button

**CSV export** — downloads a `.csv` of the current filtered/sorted view

**Lock & Share** — same lock/share flow as the Picture Wedge:
- Generates a UUID token and Experience Cloud URL
- Advances plan status to Shared with Buyer / Locked

## Prerequisites

1. `RL_Assortment_DataModel_SFDX.zip` deployed (custom objects must exist)
2. `RL_PictureWedge_LWC.zip` deployed (rlPictureWedge already in org)

## Deploy

```bash
# Replace the Apex controller and deploy the new LWC
sf project deploy start \
  --source-dir force-app \
  --target-org rl-sandbox

# Run all tests
sf apex run test \
  --class-names RLAssortmentControllerTest \
  --target-org rl-sandbox \
  --result-format human \
  --wait 5
```

## Add to a Record Page (internal — Sofia's workspace)

1. Open App Builder on `RL_Assortment_Plan__c` record page
2. Find **RL Data Wedge** in Custom Components
3. Drag it onto the page (can sit alongside or below RL Picture Wedge)
4. Set Buyer mode = **false**, Max doors = **12** (or your actual door count)
5. Save & Activate

## Add to Experience Cloud (buyer portal)

1. Open Experience Builder on your site
2. Find **RL Data Wedge** in components
3. Set Buyer mode = **true**
4. Pass `recordId` from the URL using a URL variable:
   - Page URL: `/s/assortment/{recordId}`
   - Component property: `{!recordId}`
5. Optionally validate `{token}` URL param against `Shared_Link_Token__c` in a
   guest-accessible Apex endpoint before rendering the page
6. Publish

## URL token validation (Experience Cloud guest access)

The share link generated by `generateShareToken` looks like:
```
https://your-site.com/s/assortment?planId=a0G...&token=xxxxxxxx-xxxx-4xxx-xxxx-xxxxxxxxxxxx
```

Create a before-render Apex action or a custom guest-accessible controller
that validates the token matches `RL_Assortment_Plan__c.Shared_Link_Token__c`
before the page renders — this prevents unauthenticated users guessing plan IDs.

## Relationship between rlPictureWedge and rlDataWedge

Both components are designed to be used together on the same record page:

| Feature | rlPictureWedge | rlDataWedge |
|---------|----------------|-------------|
| Primary use | Visual storytelling / buyer presentation | Data analysis / planning review |
| Resequencing | Drag-and-drop | Sorting only |
| Size run detail | No | Yes (expandable sub-row) |
| Group by | No | FOB / Tier / Delivery |
| CSV export | No | Yes |
| Buyer status | Per card (3 buttons) | Per row (combobox) |
| Both share | `RLAssortmentController` Apex class | ← same |
